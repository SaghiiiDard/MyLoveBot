# ربات پیام ناشناس + مینی‌اپ مدیریت

## دیپلوی روی Railway
1. این پوشه را در یک ریپوی GitHub (ترجیحاً **Private**) آپلود کن.
2. Railway → New Project → Deploy from GitHub repo.
3. در تب **Variables** فقط یک متغیر بساز: `BOT_TOKEN` = توکن BotFather.
4. **Settings → Networking → Generate Domain** (برای مینی‌اپ).
5. **Volume** بساز و Mount Path را `/data` بگذار (برای ماندن دیتابیس بعد از هر دیپلوی).
   مسیر دیتابیس و آدرس مینی‌اپ خودکار از Railway خوانده می‌شوند.
6. در ربات `/start` بزن (با اکانت مدیر).

## قوانین ربات
همه از داخل ربات (⚙️ قوانین ربات) یا مینی‌اپ (⚙️ بالای لیست) قابل تغییرند، بدون ری‌استارت:
نمایش/مخفی بودن هویت فرستنده، رسید بازدید، همگام‌سازی ویرایش، پاسخ مخفی، تأیید ارسال، اجازه‌ی رسانه.
متن‌های ربات هم از «ویرایش متون ربات» عوض می‌شوند.

## مدیران
آیدی‌های عددی مدیران در `config.py` (`_DEFAULT_ADMINS`) هستند؛ با متغیر اختیاری `ADMINS` هم می‌شود عوضشان کرد.
